## Pizzeria Mamma Mia con React + Vite

Proyecto Estatico, creado con React + Vite, para una pizzeria, Hito 3 actualizado

## Acceso

https://github.com/buffonico/Hito-3-Pizzeria-Mamma-Mia
https://buffonico.github.io/Hito-3-Pizzeria-Mamma-Mia/
## Descripción

    En esta oportunidad a nuestra pagina de pizzeria, se le agrego el detalle del pedido, que nos permite ver lo pedido al momento de llenar el carrito con su total.

    
  

## Tecnologías Utilizadas

- HTML5
- CSS3
- JS
- React + Vite
